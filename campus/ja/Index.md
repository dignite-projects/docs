# Dignite Campus について

Dignite Campus は日本語学校の校務システムです。学籍と在留情報、留学生のアルバイト、学生からの相談、学校からのお知らせを、一つの管理画面で扱います。

学生は自分のスマートフォンに学生用アプリを入れて学校に参加し、毎日のアルバイトの記録、給与明細の提出、学校への相談をアプリから行います。学校はその内容を管理画面で確認します。

このマニュアルは、学校の管理者と職員の方に向けて、管理画面の使い方を日常の業務の順に説明します。

## 管理画面と学生用アプリ

| | 使う人 | 使う場所 |
|---|---|---|
| 管理画面 | 学校の管理者・職員 | パソコンのブラウザで [https://console.dignite.com](https://console.dignite.com) を開きます |
| 学生用アプリ | 学生 | iPhone・Android のアプリです。日本語、英語、中国語（簡体字・繁体字）、ベトナム語、ネパール語、ミャンマー語、ベンガル語で表示できます |

## できること

- **学籍**：学生の基本情報、在留カード、在籍状態の履歴をまとめて記録します。Excel・CSV からの一括取込もできます。→ [学籍の登録と管理](students.md)、[学籍の一括取込](student-import.md)
- **学生のアプリ参加**：学生がアプリで学校に参加し、自分の学籍とつながります。→ [学生のアプリ参加と学籍の連携](app-linking.md)
- **アルバイト**：学生が毎日記録したアルバイトの時間と、提出した給与明細を、月ごとに確認できます。資格外活動の上限を超えた学生は目立つように表示します。→ [アルバイト記録](work-logs.md)、[給与明細](payslips.md)
- **学生からの相談**：学生がアプリから送った相談に、管理画面から返信します。→ [学生からの相談](consultations.md)
- **お知らせ**：クラスや入学時期などで学生を選び、アプリにお知らせを届けます。既読も確認できます。→ [お知らせの配信](announcements.md)

## 使い始めるまでの流れ

1. 無料トライアルを申し込み、管理者アカウントを設定します。→ [トライアルの申し込みと最初のログイン](getting-started.md)
2. 職員を招待し、担当に合わせてロールを割り当てます。→ [職員の招待とロール](staff-and-roles.md)
3. 学生の学籍を登録します。名簿があれば一括取込が便利です。→ [学籍の一括取込](student-import.md)
4. 学生に学校コードを伝え、アプリで学校に参加してもらいます。→ [学生のアプリ参加と学籍の連携](app-linking.md)
5. アルバイト記録のリマインダー時刻と、夏休みなどの長期休業期間を設定します。→ [リマインダーと長期休業期間](work-log-settings.md)
