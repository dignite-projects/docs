# 給与明細

学生は、アルバイト先から受け取った給与明細をアプリで撮影して提出します。内容は AI が読み取り、学生が明細と見比べて確認します。学校は、学生が確認した労働時間を月ごとに集計して確認できます。

左のメニューの「学籍管理」→「給与明細」で開きます。

## 学生がアプリで行うこと

1. 給与明細を撮影するか、画像や PDF を選んでアップロードします。
2. AI が読み取った支給日、計算期間、労働時間、支給額などを、明細と見比べて確認します。違っている項目は学生が直します。
3. アルバイト先を選んで確定します。
4. 銀行の入出金明細のスクリーンショットを添付すると、給与が振り込まれていることを照合できます。

学校の集計に入るのは、学生が確認した給与明細だけです。学生がまだ確認していない給与明細は「学生未確認」として件数だけ表示し、合計には含めません。

## 月ごとの一覧

<!-- screenshot: payslips-month.png 給与明細（月ごとの一覧） -->

「前の月」「次の月」で対象の月を切り替えます。一覧には、その月の給与明細がある学生が並びます。給与明細は、計算期間の終了日がある月に集計されます（例：計算期間が 9/16〜10/15 の明細は 10 月）。

| 列 | 内容 |
|---|---|
| 確認済み労働時間 | その月の確認済みの給与明細の労働時間の合計です。アルバイト先が複数ある学生は合算します |
| 週平均 | 確認済み労働時間を、その月の週数（月の日数 ÷ 7）で割った値です |
| 確認済み枚数 | 確認済みの給与明細の枚数です |
| 銀行明細照合済み | そのうち、銀行の入出金明細で振込を確認できた枚数です |
| 学生未確認 | 学生がまだ確認していない給与明細の枚数です |
| 差引支給額 | 確認済みの給与明細の差引支給額の合計です |

週平均が 28 時間を超えている学生には「週28時間超過」と表示されます。その月の確認済みの給与明細の計算期間がすべて学校の長期休業期間の中にある場合は、40 時間で判定します。→ [リマインダーと長期休業期間](work-log-settings.md)

日ごとの時間や 7 日間ごとの判定は、[アルバイト記録](work-logs.md)で確認できます。給与明細は月単位の確認、アルバイト記録は日単位の確認に使います。

## 学生ごとの給与明細

学生の詳細の「給与明細」タブで、その学生が提出した給与明細を確認できます。

<!-- screenshot: student-payslips-tab.png 学生の詳細の給与明細タブ -->

- 一覧には、対象年月、支払者・事業所名、労働時間、アルバイト先、記録時間、差引支給額、状態、銀行明細の照合が表示されます。
- 「詳細」を押すと、計算期間、支給日、総支給額、振込支給額、現金支給額、確認日時などが表示されます。
- 「原本を見る」で、学生が提出した給与明細の画像を表示します。
- 「学生が修正した項目」には、AI の読み取り結果から学生が直した項目が表示されます。
- 銀行明細が添付されている場合は、照合した金額、入金日、入金額、入金の摘要を表示し、「銀行明細を見る」で画像を表示します。

### 給与明細の状態

| 状態 | 意味 |
|---|---|
| 処理中 | AI が読み取っています |
| 確認待ち | 読み取りが終わり、学生の確認を待っています |
| 確認済み | 学生が確認しました。集計に入ります |
| アーカイブ済み | 学生が取り下げた給与明細です。集計に入りません |

### 銀行明細の照合

| 表示 | 意味 |
|---|---|
| 明細で確認済み | 銀行明細の中に、給与明細の振込支給額（なければ差引支給額）と同じ金額の入金がありました |
| 明細に見当たらない | 同じ金額の入金がありませんでした |
| 同額の入金が複数ある | 同じ金額の入金が複数あり、どれか決められませんでした |
| 読み取り中 | 銀行明細を読み取っています |
| 未提出 | 銀行明細が添付されていません |

同じ金額の入金が見つからない場合や複数ある場合は、学生がアプリで正しい銀行明細を添付し直すか、どの入金かを選びます。照合の結果を学校の画面から変更することはありません。

## Excel に出力する

一覧の「エクスポート」を押すと、表示中の月の内容を Excel ファイルで出力します。ファイルには「月次集計」と「明細」のシートがあります。

出力には「エクスポート」の権限が必要です（`staff` と `admin` にはあります）。
