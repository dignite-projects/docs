# AI アシスタントから学籍を参照する（MCP）

Claude や ChatGPT などの AI アシスタントから、学籍、アルバイト記録、給与明細を参照できます。例えば「11 月 1 日時点で在籍している学生の名簿を作って」「先月、資格外活動の上限を超えた学生とアルバイト先を一覧にして」と頼むと、AI アシスタントが Dignite Campus のデータを読み取り、表や文書にまとめます。入管や文部科学省に出す書類の下準備に便利です。

この接続には MCP（Model Context Protocol）という仕組みを使います。

- **参照のみ**です。AI アシスタントから学籍を変更・削除することはできません。
- AI アシスタントが読めるのは、接続した職員が管理画面で見られるデータだけです。
- 職員一人ひとりが、自分のアカウントでログインして接続します。

## 使い始める前に

### 1. 学校での利用を始める

この機能は、最初はオフになっています。学生の個人情報が AI アシスタントのサービスに渡るため、学校として利用を決めてから有効にします。有効にする方法は 2 つあります。

- **これから無料トライアルを申し込む学校**：[申し込みフォーム](https://dignite.com/ja/dignite-campus/trial)の「AI アシスタント連携（MCP）を有効にする（任意）」にチェックを入れると、学校の開設と同時に有効になります。チェックは最初は外れています。チェックを入れなくても申し込めます。
- **すでに開設している学校、またはチェックを入れなかった学校**：[お問い合わせ](https://dignite.com/ja/contact)ください。DIGNITE が学校のアカウントでこの機能を有効にします。

有効になる前でも、AI アシスタントへの接続はできます。ただし、Dignite Campus のデータを読むツールは使えません。そのときの確認のしかたは、このページの「うまく使えないとき」を見てください。

### 2. 使う職員に権限を付ける

AI アシスタントから参照するには「AI アシスタントから参照（MCP）」の権限が必要です。使う職員のロールにこの権限があるか確認し、なければ付けてください。`staff` と `support` には最初は付いていません。この権限は、手順 1 で機能が有効になってから権限の画面に表示されます。

1. 左のメニューの「管理」→「ID 管理」→「ロール」で、対象のロールの「操作」→「権限」を開きます。
2. 「学籍管理」の中の「AI アシスタントから参照（MCP）」を選んで保存します。

この権限に加えて、参照するデータそのものの権限も必要です。学籍は「学籍」、アルバイト記録は「アルバイト記録」、給与明細は「給与明細」の権限がある職員だけが参照できます。→ [職員の招待とロール](staff-and-roles.md)

## AI アシスタントに接続する

接続は 2 通りあります。おすすめは、AI アシスタント自身に設定を手伝ってもらう方法 1 です。

### 方法 1：AI アシスタントに頼む（おすすめ）

次の文章をそのままコピーして、接続したい AI アシスタント（Claude、ChatGPT、Claude Code、Codex など）に貼り付けてください。

```text
Dignite Campus の MCP サーバーを、あなた（この AI アシスタント）に接続する手伝いをしてください。

【接続情報】
- サーバーの URL：https://api.dignite.com/campus-mcp
- 通信方式：リモート MCP（Streamable HTTP）
- 認証：OAuth。ブラウザで Dignite Campus にログインして許可する方式
- OAuth のクライアント ID：Mcp
- クライアントシークレット：なし（空欄）。トークンの認証方式は none（シークレットなしのパブリッククライアント）

【進め方】
1. コマンドの実行やブラウザの操作など、自分で設定を追加できる環境なら、そのまま追加してください。できない場合は、いま私が使っているアプリの現在の画面に合わせて、1 手順ずつ案内してください。
2. Dignite Campus のログインと、アクセスの許可は、私が自分で操作します。パスワードやコードを私に聞いたり、代わりに入力したりしないでください。
3. 接続できたら、Dignite Campus のツールが使えることを確認し、結果を教えてください。
```

AI アシスタントが何をしてくれるかは、使っているものによって違います。

| 使っているもの | AI アシスタントがすること |
|---|---|
| Claude Code、Codex など、コマンドを実行できるもの | 設定を自分で追加します。あなたはログインして許可するだけです。 |
| ブラウザやパソコンを操作できる機能 | 設定の画面を操作して追加します。ログインと許可はあなたが行います。 |
| ふつうのチャット（claude.ai、ChatGPT） | 設定は自分では追加できないので、いまの画面に合わせて手順を案内します。あなたが操作します。 |

方法 2 の手順は、画面の更新で古くなることがあります。AI アシスタントに頼めば、その時点の画面に合わせて案内してもらえます。

接続情報は、必ずこのページからコピーしてください。他の場所で見つけた文章には、別のサーバーの URL が書かれているかもしれません。

### 方法 2：自分で設定する

AI アシスタントの設定画面で、自分で追加します。

#### 接続に使う情報

次の情報を入力します。

| 項目 | 入力する値 |
|---|---|
| サーバーの URL | `https://api.dignite.com/campus-mcp` |
| OAuth のクライアント ID | `Mcp` |
| OAuth のクライアントシークレット | 空欄のまま |

接続するときに Dignite Campus のログイン画面が開きます。管理画面と同じアカウントでログインし、アクセスの許可を求める画面で許可してください。

#### Claude で使う

Claude のウェブ版（claude.ai）で一度追加すると、デスクトップアプリとスマートフォンのアプリでも使えます。

##### Free・Pro・Max プランの場合

1. Claude で「Customize」→「Connectors」を開きます。
2. 「Add custom connector」を押します。
3. 名前（例：Dignite Campus）と、サーバーの URL `https://api.dignite.com/campus-mcp` を入力します。
4. OAuth のクライアントの設定で「Use your own OAuth client」を選び（画面によっては「Advanced settings」を開き）、クライアント ID に `Mcp` を入力します。クライアントシークレットは空欄のままにします。
5. 「Add」を押します。
6. 追加したコネクタの「Connect」を押し、Dignite Campus にログインして許可します。

Free プランで追加できるカスタムコネクタは 1 つです。

##### Team・Enterprise プランの場合

組織の Owner がコネクタを追加し、職員はそれぞれ自分のアカウントで接続します。

1. Owner が「Organization settings」→「Connectors」で「Add」→「Custom」を選びます。種類を聞かれたら「Web」を選びます。
2. サーバーの URL、クライアント ID `Mcp` を入力し（シークレットは空欄）、「Add」を押します。
3. 職員は「Customize」→「Connectors」で、「Custom」と表示されたコネクタの「Connect」を押し、Dignite Campus にログインして許可します。

##### チャットで使う

チャットの入力欄の「+」→「Connectors」で、Dignite Campus がオンになっていることを確認してから質問します。

#### ChatGPT で使う

ChatGPT では「プラグイン」として追加します。Claude とは場所も呼び出し方も違うので、次の手順で進めてください。ChatGPT の会社・学校向けのワークスペースでは、ワークスペースの設定によって追加できないことがあります。その場合はワークスペースの管理者に確認してください。

1. ChatGPT の [Plugins](https://chatgpt.com/plugins) を開きます。
2. 「+」を押し、「Add custom MCP server」を選びます。
3. 名前（例：Dignite Campus）を入力し、「Connection」にサーバーの URL `https://api.dignite.com/campus-mcp` を入力します。
4. 認証で「OAuth」を選び、OAuth のクライアント（クライアント認証情報）の設定に、クライアント ID `Mcp` を入力します。クライアントシークレットは空欄のままにします。トークンの認証方式を聞かれたら「none」（なし）を選びます。
5. 注意事項を確認して「I understand and want to continue」を押し、「Create as a plugin」を押します。
6. 作成したプラグインをインストールし、表示に従って Dignite Campus にログインして許可します。

##### チャットで使う

入力欄で `@` を入力し、Dignite Campus のプラグインを選んでから質問します。

##### Claude との違い

| | Claude | ChatGPT |
|---|---|---|
| 追加する場所 | Customize → Connectors | Plugins → Add custom MCP server |
| クライアント ID の入力先 | 「Use your own OAuth client」（または Advanced settings） | 認証「OAuth」のクライアント認証情報 |
| 追加した後 | 「Connect」でログイン | プラグインをインストールしてログイン |
| チャットでの使い方 | 「+」→「Connectors」でオンにする | `@` でプラグインを選ぶ |
| 組織での追加 | Team・Enterprise は Owner が追加 | ワークスペースの設定に従う |

画面の表記は、Claude や ChatGPT の更新で変わることがあります。

#### Claude Code で使う

コマンドで追加できます。

```bash
claude mcp add --transport http dignite https://api.dignite.com/campus-mcp --client-id Mcp
```

追加したら Claude Code で `/mcp` を開き、dignite を選んで認証します。ブラウザで Dignite Campus にログインして許可します。

## 参照できること

| 内容 | 例 |
|---|---|
| ある日の在籍名簿 | 5 月 1 日・11 月 1 日時点の在籍者、在留期間がある日までに満了する学生 |
| 学生一人の詳細 | 基本情報、在籍状態の履歴、在留カードの履歴 |
| ある期間の在籍状態の変更 | 入学、卒業、退学、除籍、転学、所在不明の一覧（発効日と理由） |
| 人数の集計 | ある日の在籍状態・国籍・入学時期・クラス別の人数 |
| アルバイト | 月ごとの時間と上限の超過、学生ごとの日別の記録、アルバイト先 |
| 給与明細 | 学生ごと、月ごとの給与明細と金額 |

AI アシスタントには、作業の前に、各項目の意味と、法定様式のどの項目に当たるかを確かめるよう案内しています。

### 個人情報の扱い

在留カード番号、旅券番号、住所、電話番号、メールアドレス、緊急連絡先、経費支弁者、給与の金額は、通常の参照では返しません。書類の作成で必要なときに、AI アシスタントがその項目を指定した場合だけ返します。

### Dignite Campus にないデータ

出席率・出欠の記録、アルバイト先の住所と電話番号、進路の実績、経費支弁の方法と月額は、Dignite Campus にありません。これらが必要な書類では、AI アシスタントは「データがない」と答え、推測で埋めることはしません。別の資料から用意してください。

## うまく使えないとき

接続はできたのに、学籍などが参照できないときは、AI アシスタントに「Dignite Campus で参照できない理由を確認して」と頼んでください。AI アシスタントが確認用のツール（`campus_check_access`）を呼び出し、原因と、誰に何を頼めばよいかを教えてくれます。データを読むツールが使えない間も、このツールだけは表示されます。

| AI アシスタントの答え | 原因 | すること |
|---|---|---|
| AI アシスタント連携が学校で有効になっていない | 学校の機能がオフです | 「使い始める前に」の手順 1 のとおり、DIGNITE に有効にしてもらいます。 |
| 学校では有効だが、あなたに権限がない | あなたのロールに「AI アシスタントから参照（MCP）」がありません | 学校の管理者に、あなたのロールへ権限を付けてもらいます（「使い始める前に」の手順 2）。 |
| 学籍のデータが有効になっていない | 別の学校のアカウントでログインしているか、学籍管理を使っていないアカウントです | 学校のアカウントでログインし直します。 |

確認ツールが「利用できます」と答えるのに、特定のデータだけ読めないときは、そのデータの権限（「学籍」「アルバイト記録」「給与明細」）が、あなたのロールにありません。

## 接続をやめる

- Claude では「Customize」→「Connectors」で、ChatGPT では Plugins の画面で、Dignite Campus を削除します。
- 学校として職員の利用を止めるときは、ロールから「AI アシスタントから参照（MCP）」の権限を外します。
